# Kiosk — Shop Operator (phase 2, stub)

The same kiosk shell as Intercambio, with one difference: the
Picture-in-Picture shows a **live screenshot of the shop's Windows PC**,
not a camera feed. The agent operates the shop's existing software —
taking appointments, updating records — by looking at that screen and
clicking the right controls.

Status: **stub.** This page is a placeholder that reuses the agent +
PiP shell so the layout can be reviewed before the operator harness
is connected. No shop software is driven yet, and nothing here is live.

The Intercambio prototype (`../kiosk-intercambio/`) is the working
reference implementation.
